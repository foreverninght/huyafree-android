# 虎牙轻量客户端（非官方）

一个面向 Android 的轻量直播观看客户端，读取虎牙公开网页和公开直播信息，提供直播列表、搜索、收藏、历史记录、播放和弹幕等基础能力。

> 本项目是独立的非官方客户端，与虎牙直播及其关联公司无隶属、合作或授权关系。项目不包含虎牙官方客户端代码、资源或安装包。

## 功能

- 推荐、分类、搜索、收藏和观看历史
- FLV 直播播放，支持服务器提供的画质和 CDN 线路切换
- 视频弹幕与竖屏聊天列表
- 横竖屏切换、系统画中画和后台播放
- 浅色/深色主题与弹幕显示设置
- 无账号登录，不采集用户凭据

## 技术实现

- Android 原生 Java，最低 Android 6.0（API 23）
- AndroidX Media3 / ExoPlayer 负责直播播放
- `HttpURLConnection` 访问公开页面和数据接口
- 自实现 JCE 数据读取、弹幕协议解析与绘制
- 前台服务、MediaSession 和系统画中画支持后台场景

核心代码位于 `app/src/main/java/com/huyafree`：

- `HuyaApi`：直播列表、房间信息、播放地址与线路处理
- `PlayerActivity`：播放器、画质/线路切换及窗口状态管理
- `DanmakuClient`、`DanmakuProtocol`：弹幕连接与协议解析
- `DanmakuView`、`ChatPanel`：视频弹幕和竖屏聊天显示
- `PlaybackService`：后台播放通知与媒体控制

## 构建

要求：JDK 17 或更高版本、Android SDK 34。

```powershell
./gradlew.bat assembleDebug
```

调试包生成在 `app/build/outputs/apk/debug/`。仓库不提供签名文件；发布构建请使用自己的密钥并通过本地或 CI 环境变量配置。

## 权限

- 网络与网络状态：加载直播列表、播放流和弹幕
- 前台服务与通知：后台播放及媒体控制
- 唤醒锁：维持播放过程
- 画中画：离开播放页后继续观看（设备支持时）

## 已知限制

- 仅支持当前实现兼容的 FLV 直播流
- 搜索受公开数据能力限制，采用分类匹配与本地过滤
- 上游页面、接口、签名参数或弹幕协议变化可能导致功能失效
- 不保证所有房间、线路、Android 版本和厂商系统均可用
- 后台播放由 Activity 与前台服务协作，未实现进程被系统终止后的恢复
